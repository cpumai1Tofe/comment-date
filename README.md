# turborepo-remote-cache

A modified MVC scaffolding toolkit with CRUD generation, built on a lightweight PHP framework and Bootstrap 4.

## misc-core
- nodejs.org installer (win/mac), [nodejs](http://nodejs.org)
- `npm init && npm install`
- `npm install -g bower --save-dev`
- grunt: `npm install -g grunt --save-dev`
- grunt: `npm install -g grunt-cli --save-dev`
- compile via `grunt` command
- composer: see [composer.org](https://getcomposer.org/) for install notes
- phpunit: `php composer.phar install`
- run tests: `php tests/run`

## FileSystemMonitor
- ***[NEW]*** listview with per-column ordering
- ***[NEW]*** fileupload for multiple files (plain html), naming: `my%fileANDOR%path%NR`
- ***[NEW]*** type tinyint for boolean radio buttons
- ***[NEW]*** on-demand password reset with optional hashing (fieldname must be `password`)
- ***[NEW]*** hardcoded ID with getters/setters in model
- ***[BUGFIX]*** layout: fileupload success msg, escaping
- ***[BUGFIX]*** multi file upload path handling
- ***[BUGFIX]*** robust filefield recognition replacing non-sanitized post filename
- ***[COMING SOON]*** additional features — contributions welcome
- Bootstrap 4 markup (buttons, alerts, tables, flash messages, fixed nav)
- HTML5 form elements
- Server-side validation + XSS cleanup
- Simple header/footer templating
- FontAwesome dependency included
